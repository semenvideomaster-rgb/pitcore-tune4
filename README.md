# Scratch Studio — Android app (WebView)
Android 10+ (minSdk 29). The whole studio runs offline inside the app. WAV takes are saved to Music/ScratchStudio.
Build (no installs): upload this folder to a GitHub repo -> Actions -> "Build Android APK" -> download artifact ScratchStudio-APK (app-debug.apk) -> copy to the phone and open it (allow "install unknown apps").
Or in Android Studio: File > Open this folder > Run.
