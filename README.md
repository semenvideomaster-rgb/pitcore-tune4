# Virtual Mixer (Android)

10-канальный микшер приложений для Android 13+: каждому фейдеру назначается приложение (синтезатор, драм-машина, YouTube…) и фейдер меняет громкость именно этого приложения.

- Громкость по приложениям через [Shizuku](https://shizuku.rikka.app/) (без root)
- AUTO: находит приложения, которые сейчас звучат
- MUTE / SOLO, MASTER (громкость телефона)
- ● REC: запись звука всех приложений в WAV (Музыка/VirtualMixer)
- MIDI SYNC: MIDI Clock + Start/Stop на USB-синтезаторы и синт-приложения

APK собирается автоматически (GitHub Actions) и появляется в разделе **Releases**.
