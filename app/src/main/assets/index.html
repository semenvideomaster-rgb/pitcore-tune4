VIRTUAL MIXER — КАК ПОДКЛЮЧИТЬ ЗВУК

Каждый из 10 каналов берёт звук из одного источника. Источник выбирается в списке под именем канала. Сначала нажмите 🎚 УСТРОЙСТВА и разрешите доступ: появятся названия всех входов компьютера.

1. Устройства (микрофоны, звуковые карты, синтезаторы по USB)

В списке есть все аудиовходы компьютера. Для многоканальной звуковой карты кнопка ST / L / R выбирает стерео, только левый или только правый вход.

2. Вкладка браузера (YouTube, онлайн-синтезаторы)

Выберите «Вкладка / экран», затем в окне Chrome укажите вкладку и включите «Поделиться звуком вкладки». Звук этой вкладки пойдёт только через микшер, и фейдер полностью им управляет.

3. Любые программы на компьютере (DAW, плеер, игры, софт-синты)

Браузер не может забрать звук отдельной программы напрямую. Для этого используют бесплатный виртуальный кабель:

  • Windows: установите VB-Audio Cable или VoiceMeeter (у VoiceMeeter несколько виртуальных выходов). Затем «Параметры → Система → Звук → Микшер громкости»: для каждой программы выберите выход «CABLE Input» (или VoiceMeeter Input). В Virtual Mixer на канале выберите вход «CABLE Output».
  • Mac: установите BlackHole (16ch). В программе укажите выход BlackHole, а в микшере на канале выберите вход BlackHole.
  • Можно выбрать «Весь экран» со звуком системы: в канал придёт весь звук компьютера сразу (только в Chrome на Windows).

2. На телефоне и планшете

Источники канала: встроенный микрофон, гарнитура, USB-звуковая карта, USB-микшер или синтезатор с USB-аудио (через OTG-переходник). Записи сохраняются в папку Музыка/VirtualMixer.

Канал

GAIN — входной уровень, HPF — срез низа ниже 80 Гц, HI / MID / FREQ / LOW — эквалайзер, COMP — компрессор одной ручкой, REV / DLY — посылы на ревербератор и дилей, PAN — панорама. MUTE, SOLO, фейдер в дБ. Имя канала можно переписать, нажав на него. Двойной тап по ручке или фейдеру сбрасывает значение.

MIDI

MIDI SYNC — микшер становится мастер-клоком: отправляет MIDI Clock и Start/Stop всем синтезаторам и драм-машинам. EXT — микшер сам следует внешнему клоку. MIDI LEARN: нажмите, коснитесь ручки или фейдера на экране, затем покрутите ручку на MIDI-контроллере.

⚠ Если используете микрофон, наденьте наушники, иначе будет завязка (свист).
